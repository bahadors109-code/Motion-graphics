# «دزدِ تابلو» / The Painting Thief — موشن گرافیک ۴۲ ثانیه‌ای (۱۰۸۰×۱۹۲۰)

خروجی: `output/painting-thief.mp4`

- `index.html` — انیمیشن (همان سبک «چیزی که جلوی چشم بود»: کاراکترهای سر گرد سفید روی پس‌زمینه‌ی نقاشی‌شده‌ی موزه). همه‌ی متن‌ها، دیالوگ‌ها و زیرنویس‌ها در `TT` و زمان پایان زیرنویس‌ها در `CAP_END`.
- `music.py` — موسیقی ملایم (پیانوی نرم + پد + کنترباس، فا ماژور، حدود ۷۳ BPM) و افکت‌ها؛ سنتز شده و بدون کپی‌رایت.
- `render.js` — رندر با Playwright + ffmpeg. صدای گوینده‌ی انگلیسی را در `assets/narration-en.mp3` بگذارید و جمله‌ها را در `NARRATION.segs` روی صحنه‌ها تنظیم کنید.

| زمان | صحنه |
|---|---|
| 0 – 8 | روز اول: ورود نقاش، گذاشتن تابلوی WET PAINT، نگهبان نگاه می‌کند |
| 8 – 13 | روز دوم: بوم رو به دیوار، رنگ کردن |
| 13 – 18 | گشتن جعبه‌ابزار و باز کردن دستمال، «NOTHING!» |
| 18 – 28 | روز سوم: برداشتن نقاشی، دیالوگ نگهبان و نقاش، باز کردن راه |
| 28 – 33 | مدیر و دیوار خالی، دیالوگ مدیر و نگهبان |
| 33 – 38.5 | افشای راز |
| 38.5 – 42 | نمای پایانی و متن پایان |

```bash
node render.js                      # ویدیوی کامل
node render.js --mux-only           # فقط صدا (بعد از اضافه کردن صدای گوینده)
node render.js --stills 2,9.5       # پیش‌نمایش فریم‌ها در build/
```
