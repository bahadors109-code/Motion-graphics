# «طعمه» / The Bait — موشن گرافیک ۴۶.۵ ثانیه‌ای (۱۰۸۰×۱۹۲۰)

خروجی: `output/the-bait.mp4`

- `index.html` — انیمیشن (همان سبک؛ سالن ایستگاه قطار با تابلوی حرکت قطارها، راهروی خلوت، تابلوی مقوایی، نمای دوربین مداربسته، افشای پلیس). متن‌ها در `TT`، زمان زیرنویس‌ها در `CAP_END`.
- `music.py` — موسیقی تعلیقی (تیک‌تاک ۱۶تایی، بیس پالسی، زنگ امید، ضربه روی دوربین، قدم‌های سنگین، حل‌شدن ماژور با رسیدن پلیس؛ می مینور، حدود ۹۶ BPM) و افکت‌ها؛ سنتز شده و بدون کپی‌رایت.
- `render.js` — رندر؛ صدای انگلیسی در `assets/narration-en.mp3` و جای جمله‌ها در `NARRATION.segs`.
- `script/voiceover-en.txt` — متن کامل برای ElevenLabs.
