# «جعبه‌ای که نباید باز می‌شد» / The Box That Shouldn't Be Opened — موشن گرافیک ۴۷.۵ ثانیه‌ای (۱۰۸۰×۱۹۲۰)

خروجی: `output/pastry-box.mp4`

- `index.html` — انیمیشن (همان سبک؛ فروشگاه، میز نگهبانی کنار در، جعبه شیرینی، ویترین ساعت‌ها، ساعت روی مچ کارمند). متن‌ها در `TT`، زمان زیرنویس‌ها در `CAP_END`.
- `music.py` — موسیقی بازیگوش «کِیپر» (بیس استاکاتو، پیتزیکاتو، بشکن، گلوکن‌اشپیل؛ دو مینور، حدود ۱۰۴ BPM) و افکت‌ها؛ سنتز شده و بدون کپی‌رایت.
- `render.js` — رندر؛ صدای انگلیسی در `assets/narration-en.mp3` و جای جمله‌ها در `NARRATION.segs`.
- `script/voiceover-en.txt` — متن کامل برای ElevenLabs (گوینده + دیالوگ‌ها + متن پایان، به ترتیب).
