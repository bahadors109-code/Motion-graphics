# «چیزی که جلوی چشم بود» — موشن گرافیک ۴۳ ثانیه‌ای (۱۰۸۰×۱۹۲۰)

خروجی: `output/border-smuggler.mp4`

## ساختار
- `index.html` — کل انیمیشن (Canvas، کاراکترهای دوبعدی با سر گرد سفید روی پس‌زمینه‌ی مه‌آلود). با باز کردن فایل در مرورگر پخش می‌شود؛ `?t=12.5` یک فریم مشخص را نشان می‌دهد.
- `music.py` — موسیقی پس‌زمینه (پیتزیکاتوی معمایی-طنز در رِ مینور، ۹۶ BPM) و افکت‌ها؛ کاملاً سنتز شده و بدون کپی‌رایت.
- `render.js` — رندر فریم‌به‌فریم با Playwright + ffmpeg و میکس صدا (داکینگ موسیقی زیر صدای گوینده).
- `assets/narration.mp3` — صدای گوینده. در ثانیه‌ی 22.1 فایل، ۲.۶ ثانیه فاصله برای دیالوگ مرزبان (حباب گفت‌وگو) باز می‌شود.

## زمان‌بندی (ثانیه‌ی ویدیو)
| زمان | صحنه |
|---|---|
| 0 – 5.6 | عبور اول، تیتر، ایست بازرسی |
| 5.6 – 12.9 | بازرسی گونی، «شن؟!» |
| 12.9 – 17.5 | ماه دوم، دوچرخه آبی، ذره‌بین |
| 17.5 – 22.4 | ماه سوم، دوچرخه مشکی، «الک ویژه!» |
| 22.4 – 28.0 | پرت کردن گونی، حباب دیالوگ، شانه بالا انداختن، عبور از «مرز» |
| 28.0 – 31.3 | فروش دوچرخه، «فروخته شد!» |
| 31.3 – 39.1 | فلش‌بک سه عبور، محو شدن گونی‌ها، برجسته شدن «دوچرخه ۱/۲/۳» |
| 39.1 – 43.0 | مرزبان هنوز الک می‌کند، «گونی‌ها فقط حواس‌پرتی بودن!» |

## پس‌زمینه‌ی عکس واقعی
پس‌زمینه‌ها به‌صورت نقاشی دیجیتال ساخته می‌شوند. برای استفاده از عکس واقعی، فایل‌های
`assets/bg-border.jpg` و `assets/bg-village.jpg` (۱۶۲۰×۲۴۰۰؛ خط زمین/جاده حدود y=1700 تصویر) را اضافه کنید و دوباره رندر بگیرید.

## رندر
```bash
npm i playwright   # اگر نصب نیست
node render.js                       # ویدیوی کامل
node render.js --stills 2,9.5,23.5   # پیش‌نمایش چند فریم در build/
```
