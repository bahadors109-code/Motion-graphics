# ۱. قهر با ترازو — موشن گرافیک طنز (۳۵ ثانیه)

- **ویدیو نهایی:** `ghahr-ba-tarazoo.mp4` — عمودی ۱۰۸۰×۱۹۲۰ (۹:۱۶)، ۳۰ فریم، ۳۵ ثانیه، بدون صدا
- **سورس انیمیشن:** `index.html` — با مرورگر باز کنید (Play / اسکراب)
- **رندر دوباره:** `node render.cjs [out.mp4] [fps]` (نیاز به Playwright + ffmpeg)

سبک: تصویرسازی فلت با رنگ‌های قرمز/آبی/زرد، خطوط چین‌دار، بافت راه‌راه و شطرنجی، موج زرد با رگه‌های چوبی و هواپیمای کاغذی.

| زمان | صحنه |
|---|---|
| ۰–۶ | خانم کفش‌ها را پرت می‌کند، روی ترازو می‌رود (۶۸٫۵)، پیاده و دوباره سوار می‌شود — همان عدد! «؟!» |
| ۶–۱۴ | ترازو چشم و دهان پیدا می‌کند و حرف می‌زند؛ حباب‌های فکر: «حذف وعده» و «خوردن بی‌برنامه» |
| ۱۴–۲۳ | پیام مربی روی گوشی؛ خانم آن را کنار می‌زند، زوم روی لبخند معذب + استیکرهای چک‌لیست / تغییر / «شنبه» |
| ۲۳–۳۵ | فضا تیره می‌شود، روی نیمکت می‌نشیند، پیام صوتی می‌فرستد (هواپیمای کاغذی) → «برنامه‌ای که بتونی ادامه بدی.» |
