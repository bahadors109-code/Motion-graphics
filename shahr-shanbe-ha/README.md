# شهر شنبه‌ها — موشن گرافیک فانتزی و داستانی (۳۶ ثانیه)

- **ویدیو:** `shahr-shanbe-ha.mp4` — عمودی ۱۰۸۰×۱۹۲۰ (۹:۱۶)، ۳۰ فریم، ۳۶ ثانیه (فعلاً بدون صدا)
- **سورس:** `index.html` — در مرورگر باز کنید (Play / اسکراب)
- **رندر:** `node render.cjs` — اگر `assets/narration.mp3` وجود داشته باشد، خودکار روی ویدیو میکس می‌شود

| زمان | صحنه |
|---|---|
| ۰–۶ | خانم روی تردمیل می‌دود؛ دوربین عقب می‌رود و شهری پر از تابلوهای «از شنبه» دیده می‌شود |
| ۶–۱۵ | سه نسخه از خانم: شنبه با ساک باشگاه، یکشنبه با برگه‌ی «رژیم سخت»، دوشنبه همه خسته، سه‌شنبه پیام مربی را می‌بندد: «هفته بعد جبران می‌کنم!» |
| ۱۵–۲۳ | برگه‌های تقویم دورش می‌چرخند، روی ترازو می‌رود، آه می‌کشد و روی نیمکت می‌نشیند |
| ۲۳–۳۶ | تقویم می‌ایستد و برگه‌ها می‌ریزند؛ تابلوی «از شنبه» را به «امروز» برمی‌گرداند، کنار مربی اولین قدم را می‌نویسد → «شروع کوچیک؛ ادامه‌ی واقعی.» |

زمان زیرنویس‌ها در آرایه‌ی `CAPS` داخل `index.html` است؛ با رسیدن صدای گوینده، با همان روش ویدیوی «قهر با ترازو» همگام می‌شود.
